# Security Policy

## Supported Versions

Currently, this project is in a pre-1.0 state. We only actively support the current major version.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues. 
Because this repository handles sensitive data like keypairs and signing, public disclosure could put users at risk.

Instead, please report vulnerabilities privately via GitHub's "Report a vulnerability" security advisory feature on this repository.

## Response Time

We aim to acknowledge reports within 72 hours and will work diligently to provide a patch or mitigation as soon as possible.
